# Portafolio de Diseño Web – Heymar Gaspar Torrejo

Sitio web responsivo de portafolio personal desarrollado para el **Examen Parcial de Diseño Web** (ISI-FE2301, 2026-II).

## Tecnologías utilizadas
- **HTML5** semántico (`header`, `nav`, `main`, `section`, `article`, `footer`)
- **CSS3**: selectores `id`/`class`, cajas flotantes (`float` + `clear`), `transition`, `transform`, `@keyframes`
- **Multimedia**: `<video>` y `<audio>` locales, `<iframe>` de YouTube
- **Diseño responsivo** con 2 `@media` queries (< 768px y ≥ 768px)
- **SEO básico**: `title`, `description`, `keywords`, `viewport`, atributos `alt`
- **GitHub Pages** para la publicación

## Estructura
```
index.html
css/style.css
img/    (imágenes jpg)
media/  (audio y video locales)
```
